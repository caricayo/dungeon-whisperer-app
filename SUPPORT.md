# Support

## Getting Help

If you need help with Dungeon Whisperer, here are your options:

### Documentation

- **README.md** - Getting started guide and basic setup
- **docs/** - Detailed documentation and guides
- **SECURITY_FIXES_IMPLEMENTED.md** - Security implementation details

### Community Support

1. **GitHub Issues** - For bug reports and feature requests
   - Search existing issues first
   - Use appropriate issue templates
   - Provide clear reproduction steps

2. **GitHub Discussions** - For questions and community help
   - General questions about usage
   - Feature discussions
   - Community showcase

### Reporting Issues

When reporting a bug, please include:

- Operating system and version
- Node.js version
- Browser version (if applicable)
- Steps to reproduce the issue
- Expected vs actual behavior
- Error messages or logs
- Screenshots (if relevant)

### Feature Requests

For new features:

- Check if the feature already exists
- Describe the use case clearly
- Explain why this would be valuable
- Consider implementation complexity

### Security Issues

**DO NOT** report security vulnerabilities as public issues.

Please see our [Security Policy](SECURITY.md) for responsible disclosure.

### Performance Issues

For performance problems:

- Include system specifications
- Describe the performance issue
- Provide timing information if possible
- Include relevant logs

### Response Times

- **Bug reports**: We aim to respond within 48 hours
- **Feature requests**: Response within 1 week
- **Security issues**: Response within 24 hours (see SECURITY.md)
- **General questions**: Community-driven, varies

### Prerequisites

Before asking for help:

1. Check the documentation
2. Search existing issues
3. Try the latest version
4. Verify your setup meets requirements

### Code of Conduct

All interactions must follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Commercial Support

For enterprise or commercial support needs, please contact us through GitHub or email.
