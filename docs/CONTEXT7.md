# Context7 Documentation Integration

## Overview

Context7 (https://context7.com) is an up-to-date documentation resource for LLMs and AI code editors that can be used as an MCP (Model Context Protocol) server.

## What is Context7?

Context7 provides:
- Latest documentation for AI development tools
- Real-time updates on LLM capabilities and best practices  
- Integration guides for popular AI code editors
- MCP server functionality for enhanced AI assistance

## Using Context7 as MCP Server

### With Cursor
1. Install the Context7 MCP server
2. Configure your Cursor settings to connect to Context7
3. Access real-time documentation during development

### With Claude Desktop
1. Add Context7 as an MCP server in Claude Desktop configuration
2. Enable the server to access latest AI development documentation
3. Query Context7 directly for current best practices

## Integration in This App

This app includes Context7 integration through:

### Smart Documentation Suggestions
- Automatic detection of technical terms in user messages
- Contextual links to relevant Context7 documentation
- Real-time access to the latest AI development practices

### How It Works
1. When you type technical terms, the system detects relevant technologies
2. A "Open latest docs" button appears with a direct link to Context7
3. Your query is automatically encoded and sent to Context7 for relevant results

### Supported Technologies
- React, TypeScript, Tailwind CSS
- Supabase, PostgreSQL
- AI/LLM development tools
- Testing frameworks (Playwright, Vitest)
- And many more...

## Privacy & Security

- No user input is sent to external services without explicit user action
- All Context7 links are generated client-side
- User settings control when suggestions appear
- Demo mode compliance ensures safe operation

## Configuration

You can control Context7 integration through Settings:
- Enable/disable documentation suggestions
- Customize which technologies trigger suggestions
- Set preference for automatic vs manual documentation access

## Benefits

- Always access the most current documentation
- Reduce context switching between tools
- Get AI-specific guidance for your development workflow
- Stay updated with latest best practices in AI development
